# 7月2日更新公告丨烽火挑战即将开启&问题修复

干员朋友们好：

我们计划于7月2日进行不停机更新，更新期间不会影响正常游玩与匹配。
如您在更新后遇到异常问题，可尝试重启游戏完成更新解决。

本次更新主要内容如下：

## 烽火挑战开启
本赛季开启时间：
| 赛段一 | 赛段二 |
| ---- | ---- |
| 7月4日18:00-7月18日2:00，每日18:00-次日2:00； | 8月8日18:00-8月22日2:00，每日18:00-次日2:00； |
| 休赛期仍可查看烽火挑战奖励进度 | |

- 赛段一7月18日2:00-7月19日23:59:59休赛；
- 赛段二8月22日2:00-8月23日23:59:59休赛；
- 休赛期仍可前往页面领取已获得的奖励；
- 赛段二开启时将继承赛程一的奖励和对局进度；
- 每个赛段开启时将自动发放1张免费烽火挑战券，并可通过活动获取3张免费烽火挑战券，共计4张。

### 奖励优化
- 新增挑战奖励手册：参与烽火挑战获取积分，提升手册等级，获取奖励。
- 奖励内包含烽火挑战幸运箱（可获取烽火挑战专属防具）、传说品质武器外观—M250通用机枪-军阀、专属头像、喷漆等。

### 门票调整
- 烽火挑战券价值调整，可使用哈夫币/三角券购买烽火挑战券（初始参赛票价降低，随参赛次数梯度升高，每赛段也将发放免费赠票）。
- 新增社交定制相关：
  - 新增烽火挑战赛季专属称号。并根据奖励手册等级的提高而提升称号等级；
  - 新增赛季专属砖业团队成就，并根据获取次数而提升成就等级。
- 配置体验优化：现支持一键配置、应用配置方案。
- 门禁卡包体验优化：报名成功后，自动发放门禁钥匙卡到玩家背包，无需额外购买。
- 击败补给价值提升：身份牌价值随对局场次的增加而提升。
- 优化了终局结算界面的表现。

7月3日0:00-7月23日23:59:59
