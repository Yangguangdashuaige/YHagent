# 12月26日更新公告丨全面战场平衡性调整&活动上新！

干员朋友们好：
我们计划于12月26日进行不停机更新，更新期间不会影响正常游玩与匹配。

如您在更新后遇到异常问题，可尝试重启游戏完成更新解决。

本次更新主要内容如下：

## 全面战场平衡性调整
- 烬区攻防模式优化了据点A的占领范围；
- 攀升攻防模式优化了四个据点的占领范围；
- 移动端烬区攻防模式中A区域奖励票数降低15，并增加了移动端靠近旗帜时的占领力；
- 移动端贯穿攻防模式中初始票数下调50票，以保持与其他地图一致，并增加了移动端靠近旗帜时的占领力，以优化移动端贯穿地图对局时间过长的现象；
- 阵地支援分数调整：
  - 炮兵齐射分数由8000下调到7000；
  - 战略信标分数由9000下调到8000；
  - 轮式突击炮分数由10000下调到9000；
  - 突击车分数从由6000下调到5000；
  - 攀升攻防模式制导导弹所需要的分数由18000上调到20000。
