# 方舟联动特别赠礼活动预告

**干员朋友们好：**

**感谢大家对《三角洲行动》与《明日方舟》联动的关注与期待。**
**本次联动我们将推出丰富的内容与活动。干员们可以免费获得两款传说品质阿米娅武器外观、阿米娅头像与军牌、联动收集物等道具，游戏关卡中还有不少彩蛋等待大家发现。**

**除此之外，我们也为大家准备了方舟联动的特别赠礼：**
**7月11日将开启赠礼活动，完成简单活动任务，可免费获得方洲行动干员研究-专属研究资格券。**
**方洲行动干员研究开启期间，保底可得90张专属的研究资格券（价值9000三角币）。**

**在露娜方洲行动干员研究活动期间，即可解锁全部赠礼，资格券可用于参与露娜、蛊、骇爪的任意方洲行动干员研究，活动持续至方洲行动干员研究结束。**

**再次感谢大家的理解与支持，预祝大家新版本游戏愉快！**
