## 返还规则
充值返还计算说明：正式上线返还的三角币=充值金额*10*返还比例+充值赠送部分

注：1元=10三角币
1. 充值金额部分：根据梯度返还充值金额

返还比例如下：

| 充值金额 | 返还比例 |
| --- | --- |
| 包括以下行为产生的付费金额：1、三角币充值2、起源补给购买 | 充值金额≤2000元该区间充值按照155%的比例返还 |
| | 2000＜充值金额≤6000元该区间充值按照135%的比例返还 |
| | 充值金额＞6000元该区间充值按照100%的比例返还 |

2. 充值赠送部分：返还实际充值档位所获得的赠送三角币

举例：充值648元，可获得（648*10+1620）三角币，其中1620三角币属于充值赠送部分

注：起源补给与6元充值档位没有赠送三角币

## 曼德尔砖与典藏外观规则
1. 曼德尔砖获取方式：危险行动中拾取并破译/全面战场排名前列；通过市场购买其他干员上架的曼德尔砖（购买者使用三角币支付，出售者获得三角券）。
2. 曼德尔砖开启方式：三角币购买量子秘钥开启，或三角券兑换量子秘钥开启（周期限量）。
3. 当前版本曼德尔砖产物：终极奖励“M4A1-棱镜攻势”，及其他共计22款典藏外观。
4. 典藏外观交易：典藏外观支持上架市场交易（购买者使用三角币支付，出售者获得三角券）。
5. 典藏外观特性：典藏外观将有不同成色外观、终极奖励还包含专属编号及特殊武器检视/曳光弹/命中效果/枪口火焰等特性。
6. 典藏外观重组：典藏外观支持重组，每20个典藏外观可重组成1个更高品阶的典藏外观。
（例：20个史诗典藏外观可重组合成为1个传说典藏外观）

## 典藏外观保留规则
1. 每开启1个曼德尔砖获得1款典藏外观，删档测试期间可选择一款典藏外观免费保留至正式上线。
2. 可保留的典藏外观没有品级限制，可根据喜好在充值返还查询网页上进行选择。
3. 删档测试期间，您可以随时在【充值返还查询界面】调整想要保留的典藏外观；测试结束后，无法再进行典藏外观的保留变更。
4. 【充值返还查询界面】仅能选择藏品仓库中的典藏外观，处于交易状态的典藏外观无法被选择。

举例：若先选择保留1款典藏外观，后将该典藏外观上架市场或出售成功，充值返还查询网页保留的选择将变为无效，您需要重新选择需要保留的典藏外观。
5. 请在测试结束前确认您选择保留的典藏外观在藏品仓库中，以确保该典藏外观在正式上线后正常发放。
6. 典藏传说外观带有特殊编号，编号顺序为生成时间排序，编号会继承到上线且带有特殊纪念前缀。
7. 典藏外观表现以游戏内实际表现为准。

1. 请在游戏正式上线时，使用与删档测试期间相同的账号游玩（同一QQ或微信账号），确保充值返还的三角币与典藏外观的正常领取与发放。
2. 本次测试iOS端因TestFlight限制，无法进行充值，干员可于PC端/安卓端进行付费充值，付费内容全端互通；同一QQ或微信账号在PC端/安卓端上的充值数据均计入总充值金额，并按照上述充值返还规则进行返还。

4. 请务必在游戏正式上线后180个自然日内完成角色注册流程并进行返还三角币的领取流程，逾期未注册游戏账号或未领取视为主动放弃返还奖励。
5. 若在测试期间内获得典藏外观但未进行保留选择，视为主动放弃典藏外观的保留资格。
6. 如果任何疑问，请联系腾讯客服协助解决，感谢支持。
