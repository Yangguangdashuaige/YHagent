# 烽火地带新手入门（示例文档，建库验证用，请替换为真实资料）

> 这是用于验证知识库链路的示例文档，内容为占位说明。正式使用时请用从 Wiki 整理的真实攻略替换本文件。

本文解答新手在烽火地带（撤离类模式）中的基础问题：带什么装备进局、死亡后损失什么、怎么安全撤离。

## 进局前的配装思路

新手阶段的核心原则是"带得起、亏得少"：优先使用低成本但够用的白绿品质装备，把高价值装备留在熟悉地图后再使用。

### 推荐的新手配装

| 装备位 | 推荐选择 | 原因 |
|---|---|---|
| 主武器 | 后坐力低、弹药便宜的步枪或射手步枪 | 压枪门槛低，容错高 |
| 护甲 | 白色或绿色头盔+防弹衣 | 成本低，被击败也不心疼 |
| 背包 | 中型背包 | 留出空间装缴获物资 |
| 药品 | 基础急救包+止疼药各2个 | 覆盖大部分交战场景 |
| 弹药 | 带足1~2个弹匣的备弹 | 避免中途缺弹无法还击 |

### 不建议新手携带的物品

- 红色、金色等高价值武器和护甲：一旦被击败损失极大；
- 大量现金：死亡掉落风险高于收益；
- 不熟悉弹道的高价枪械：装备价值不等于战斗力。

## 死亡惩罚与物资带出

在烽火地带中，角色被击败后，**本局带入和缴获的未保险物资会全部损失**；成功撤离则可以带出背包内全部物资并存入仓库。因此新手前期的目标不是击杀，而是：

1. 选择冷门落点，避开开局交火；
2. 边搜集边向撤离点移动，见好就收；
3. 听到密集枪声主动绕开，不主动接战；
4. 背包价值达到心理预期后立刻撤离，不贪。

## 撤离点与撤离技巧

撤离点在地图上有固定位置，部分撤离点需要满足开启条件（等待读秒、支付道具或特定时间段开放）。到达撤离点后通常需要在范围内停留一段时间，期间应：

- 提前清理附近高点和反斜方向的敌人；
- 利用载具或烟雾弹掩护读秒；
- 和队友错开站位，避免被一颗雷同时淘汰。
