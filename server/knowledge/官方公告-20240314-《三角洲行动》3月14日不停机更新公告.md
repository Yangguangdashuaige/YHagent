# 《三角洲行动》3月14日不停机更新公告

> 官方公告 | 分类：公告 | 发布时间：2024-03-14 14:44:42 | 文档ID：13709146160354929141
> 来源：https://df.qq.com/cp/a20240906main/newsdetail.html?id=13709146160354929141

干员朋友们好，我们已于3月14日发布了不停机更新版本，敬请知悉。
本次更新主要内容如下：

【平衡性调整】
地图“攀升”、“烬区”平衡性调整；

【问题修复】
修复了干员蜂医烟墙无人机标识丢失的问题；
修复了干员红狼战术滑铲失效的问题；
修复了干员红狼外骨骼模型显示异常的问题；
修复了曼德尔砖开启后获得重复外观的问题；
修复了偶现曼德尔砖无法交互的问题；
修复了全面战场模式中，偶现被击败角色模型仍有碰撞的问题；
修复了危险行动状态栏头盔护甲耐久显示异常的问题；

以上，本次热更新已完成；如遇异常问题请重启游戏更新至最新版本或联系各平台官方账号管理员。
感谢干员朋友们的理解与支持！
