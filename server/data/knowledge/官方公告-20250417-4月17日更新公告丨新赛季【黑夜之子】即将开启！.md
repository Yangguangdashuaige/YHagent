# 4月17日更新公告丨新赛季【黑夜之子】即将开启！

> 官方公告 | 分类：公告 | 发布时间：2025-04-15（4月17日更新） | 文档ID：无（纯图片长图公告，来源为官方长图截图，经视觉 OCR 转写）
> 注：本文是 S4 赛季【黑夜之子】更新内容，涵盖新干员无名、夜战地图、武器/干员平衡数值、活动与物流等。

干员朋友们好：
我们计划于4月17日不停机更新游戏版本，开启全新赛季【黑夜之子】！

预计更新节奏如下：
1. 4月17日凌晨0:30~2:00，双模式排位赛休赛暂时关闭。
2. 4月17日2:00，烽火地带模式匹配及交易功能暂时关闭。
3. 4月17日2:00，开放iOS端更新（以App Store上架新版本时间为准）。
4. 4月17日3:00，开放PC端、安卓端版本更新。
5. 4月17日9:00开放安卓渠道商店更新（以渠道商店上架新安装包时间为准）。

如您在更新期间遇到异常问题或错误提示，请在以上时间更新完成后重启游戏并更新至最新客户端版本。

更新完成后，将开启全新赛季【黑夜之子】！

新赛季将加入：新突击干员埃利.德.蒙贝尔，代号无名、零号大坝-夜战、堑壕战-夜战、新武器、新配件、新载具，以及活动玩法、大量玩法优化和缺陷问题修复。

赛季更新详细内容如下，欢迎干员们体验！

## 玩法更新
### 新突击干员：埃利.德.蒙贝尔，代号无名
- 干员特长-重伤延滞：被无名伤害的敌人在烽火地带模式中使用药品治疗、倒地被扶起时均需花费更多时间；全面战场中将延长脱战自动恢复的时间。
- 战术装备-静默潜袭：启动装备的干扰器，对附近敌人造成干扰，大幅降低无名发出的声音，提升无名的机动性；装备开启期间，烽火地带侦察道具只能检测干扰器起始位置，全面战场无法侦察到无名。
- 战术道具-旋刃飞行器：投掷一枚具备索敌追踪功能的小型飞行器，靠近敌人后爆炸造成伤害和伤口并减速。面对背身敌人时锁定更快，无锁定直接投掷会在短时间后爆炸。
- 战术道具-突破型闪光弹：向前投掷一枚触碰到墙体后会爆闪的闪光弹，对附近所有敌人进行闪光震撼。

### 零号大坝-夜战
- 新增地图：零号大坝-夜战，包含前夜/长夜/终夜三种难度的行动。地图中光源较少、可视度极低，可以通过夜视仪或热成像等装备和道具获得更多信息优势！

### 堑壕夜战
- 新增地图：堑壕战-夜战。战斗时间来到黄昏和夜晚，更昏暗的视线带来更沉浸的战斗体验。新增夜战阵地支援-夜视仪。

### 新武器——K437突击步枪、725双管霰弹枪

### 新弹药/新配件/新装备——龙息弹、新增夜视仪头盔
- 新弹药：.300BLK、龙息弹
- 新装备：夜视仪头盔

### 新载具/新改装配件——GTQ-35轻型坦克、兵种道具喷火器
- GTQ-35轻型坦克：拥有更强劲的机动性和转向能力，可释放独立操作的无人机进行侦查和爆破，侧面拥有可减伤的爆炸反应装甲；驾驶位可使用105mm主炮及轻重机枪，主炮可升级为具备追踪功能的炮射导弹；武器站全面升级为复合武器站，可自由切换并列机枪与榴弹发射器；
- 喷火器：新增突击、工程兵种道具喷火器，可发射火焰。

### 全面战场限时模式——胜者为王
- 胜者为王：赢，才是唯一的王道。指定段位可参与的20vs20限时玩法，票选的指挥官可通过特殊语音频道、标记系统、阵地支援调动队伍、分配资源，带领队伍取得胜利；
- 阵营频道：指挥官和小队队长均可以在阵营频道中使用麦克风面向全阵营讲话；
- 战术标记：指挥官可以在大地图界面使用战术标记，精确标点传达战术意图；
- 阵地支援：新增标记高价值据点和标记高威胁载具两种指挥官专属阵地支援，明确战术目标，获得额外奖励。
- 节奏调整：对胜者为王模式下部分参数进行了修改。适当增加了部署冷却时间，全干员战术装备和道具的冷却时间，得分事件和空投载具积分系数；适当降低了对局总兵力数和载具数量，降低了头标和地图红点的显示距离，以及呼吸回复生命值的速率。

### 赛季任务更新
- S3赛季任务线进度重置：将重置并清空所有S3赛季任务线进度；过往赛季获取的【顶级安全箱赛季权限】，以及未使用的【3x3体验卡（包括1天、2天和3天版本）】将逾期失效，无法再使用；
- S4赛季任务线更新：S4赛季全新赛季任务线开启，77个新赛季任务等待干员挑战；
- 赛季任务优化：任务目标为【任务过程中如撤离失败则重置整个任务进度】的任务，在战局内进入【任务完成】状态后，将不再会因为撤离失败、中途退出等原因被重置；
- 赛季任务经验值收益调整：由于赛季任务和部门任务已经提供了丰厚的物资和经验奖励，后续赛季任务提供的角色经验值将在原有基础上下调50%。

## 玩法调优
### 局内战斗&关卡优化（烽火地带）
- 音频：优化听声辨位逻辑，新增基于对象的双耳声，带来更精准的3D定位，可以在设置-音频-HRTF选项中选择打开。修复了耳机模式下声音角度不准确的问题，现在能更清晰地区分立体结构中楼上楼下的声音来源。
- 角色战斗动作：优化了探头射击时，部分动作导致对手仅漏出少量头部或侧身身位的现象；
- 角色机动性：优化了角色跨越时的机动性，降低机动性损失；
- 零号大坝：部分地图平衡点位调整；
- 物品模型：优化了物品“微型反应炉”和“便携军用雷达”在对局中显示的模型尺寸；
- 物品检视：新增棘龙爪化石、步战车模型、便携军用雷达、摄影机、名贵机械表的物品检视；
- PC端自定义投掷及部署方式：设置-操控&战斗页面中，可在快投、手持、默认三种方式中切换部分战术道具的使用方式（例如：设置快投后，佐娅可直接投掷出致盲毒雾）；
- 新增闪光护眼模式：开启后可将被闪光巡飞器命中后的效果调整为暗色；
- 磁吸炸弹提示：角色被磁吸炸弹吸附时，会显示特殊图标；
- 巴克什首领蓝鹰直升机：优化了坠机地点逻辑，优先坠落在击落点位附近，折翼行动必定落在停机坪；优化了直升机巡逻路线，及火箭弹伤害显示逻辑（实际伤害值无改动）；

### 局内战斗&关卡优化（全面战场）
- 临界点（攻防）：全新地图事件加入，C1区被多发制导导弹命中后将坍塌摧毁，成为中立据点；（由于地形变化，C1据点中的烽火地带密码位置将略微调整）
- 临界点（攻防）：新增局内事件，当进攻方C区兵力值低于75时，将触发空中支援轰炸，开启C2据点全新进攻通道；
- 临界点（攻防）：C2据点范围平衡性调整；所有区域攻方突击车的重新部署冷却时间降低到40秒；制导导弹所需分数下调至17000；
- 临界点（占领）：双方突击车的重新部署冷却时间降低到40秒；
- 临界点（占领）：轮式突击炮替换为轻型坦克；
- 堑壕战：左侧山体部分调整，增加可玩区域，优化部分交火点位；
- 堑壕战端游（占领）：扩大了整体的可玩区域，新增一个占领区域；
- 堑壕战（攻防）：第四个区域进攻方的轮式突击炮替换为轻型坦克；
- 断轨（攻防）：第一个区域进攻方阵营的轮式突击炮替换为轻型坦克；
- 断轨（占领）：新增轻型坦克；
- 侦查直升机：重新部署时间全部调整为150s；
- LAV-25防空车：重新部署时间全部调整为90s；
- 攀升/烬区/堑壕战钢铁洪流模式：端游主战坦克数量减少两辆，增加两辆轻型坦克；手游主战坦克数量减少一辆，增加一辆轻型坦克。
- 断轨-钢铁洪流模式：主战坦克数量减少两辆，增加两辆轻型坦克；
- 对局结算：结算面板优化，新增军械库/干员成长/干员成就/干员招募/藏品外观等多维度任务列表及进度展示；
- 载具平衡性调整：防御榴弹缩小爆炸范围并增加冷却时间；线控导弹增加速度和加速度；优化载具撞击速度判定，一定速度区间内撞击损伤降低；
- 角色战斗动作：优化了探头射击时，部分动作导致对手仅漏出少量头部或侧身身位的现象；
- 角色机动性：优化了角色跨越时的机动性，降低机动性损失；
- 空投载具：新增重复呼叫空投载具积分膨胀系数，多次呼叫空投载具需要更多积分了；
- 投掷物显示：优化了对角色产生威胁投掷物的警示图标，隔墙时将以镂空形式展示；
- PC端自定义投掷及部署方式：设置-操控&战斗页面中，可在快投、手持、默认三种方式中切换部分战术道具及全面战场兵种道具的使用方式（例如：设置快投后，佐娅可直接投掷出致盲毒雾）；
- 新增闪光护眼模式：开启后可将被闪光巡飞器命中后的效果调整为暗色；
- 磁吸炸弹提示：角色被磁吸炸弹吸附时，会显示特殊图标；

## 系统优化
### 系统优化（全模式）
- 模式选择面板：优化了模式选择面板的展示方式，并提供了快速参加活动的按钮；
- 干员档案：优化了所需任务数量，并平衡了任务难度；
- 改枪台：新增了瞄具准心预览功能，开启后可在改装瞄具时预览准心样式；
- 改枪台：新增了配件列表筛选功能，可根据需求属性进行配件筛选；更新了改枪方案推荐；
- 改枪码：聊天频道可以快速发送和复制改枪码了；
- 藏品：优化了自选包的使用功能，可以开启自定义数量的自选包了；
- 新手引导：PC端新增了局内撤离点图文教学、系统玩法教学和语音引导；
- 好友系统：新增好友备注功能，可自定义好友备注；
- 操作与设置：移动端支持跳跃与翻越操作分离；移动端支持独立设置“开火打断换弹”功能；
- 移动端输入延迟：优化降低了移动端滑屏与按键的输入延迟；
- 市场：曼德尔砖支持挂单收购，新增典藏外观、典藏挂饰关注列表，购买往期曼德尔砖易用性优化；
- 枪械外观随机：新增随机枪械外观入局功能；

### 系统优化（烽火地带）
- 作弊击败补偿：优化了补偿范围的算法，现在能够对更长时间的对局进行回溯和补偿；
- 交易行：上架界面支持点击柱状图快速切换价格；
- 交易行：当所选物品军需处价格更低时，将通过更低价的军需处兑换价格进行购买；
- 兑换和制造配方调整：研发部门限时商品的兑换利润提升，大幅提高了研发成果中钥匙等稀有物品的刷出概率，并有小概率刷出6级战斗物资制造所需材料；
- 兑换和制造配方调整：调整了先进全息热成像及先进战斗热成像瞄具和其他关联兑换制造配方；新增了夜视仪相关制造配方；
- 兑换和制造配方调整：交易行上架了OLIGHT WARRIOR 3S战术手电配件，同时上架了制造所需的手电收集品材料；
- 追缴系统调整：哈夫币追缴处罚现在不会直接扣负，而是被记录为追缴值，账号的每一笔哈夫币收益都将被抽取一定比例用于偿还追缴额，在哈夫币充足时也可选择手动归还；当前哈夫币余额为负数的账号，将于系统上线后统一将负数追缴额调整至追缴系统，不再影响烽火地带的交易行上架和正常装备购买；

- 新手教学：新增烽火地带新手撤离教学；
- 制式装备券：制式装备券可以直接应用默认武器外观了；
- 配装系统：新增护甲购买可选耐久度功能、新增药品可选耐久携带功能、新增安全箱过期配装提醒、新增夜战配装提醒、优化了精锐装备券物资分配、优化了快捷兑换功能及价格展示和售罄提醒界面、优化了带入限制文本；
- 仓库：优化了仓库界面的表现、优化了移动端导航栏提示；

### 系统优化（全面战场）
- 地图禁用：全面战场支持在赛单中手动选择禁用最多2张地图，禁用后将不会匹配到选择的地图；
- 计分板统计方式调整：
  - 救治贡献统计方式修改为：治疗行为+救援行为所产生的分数/100；
  - 占点贡献修改为：占点行为所产生的分数/100；
  - 工程贡献修改为：工事相关行为+载具相关行为所产生分数/100；
  - 战术贡献修改为：干员装备道具+阵地支援产生分数/100。
- 同阵营头标：移除了头标的距离信息，减少了友方昵称的显示距离，优化了随距离缩放的表现；
- 改枪台：优化了预安装和应用方案时的交互体验；
