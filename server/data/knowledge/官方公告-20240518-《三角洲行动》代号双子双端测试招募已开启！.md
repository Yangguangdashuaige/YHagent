# 《三角洲行动》代号双子双端测试招募已开启！

干员朋友们好！

《三角洲行动》双端测试现已开启招募报名，欢迎前往游戏官网和各社区平台填写招募问卷报名。

我们整理了本次测试的主要信息及常见FAQ为大家提供帮助和参考。

## 双端测试主要信息
- 测试开启时间：预计2024年6月中旬
- 测试结束时间：请留意后续官方公告
- 报名方式：前往游戏官方网站或各社区平台填写招募问卷报名。
- 测试资格发放方式：首批资格预计6月10日开通并发送短信提醒，请留意报名手机短信或关注官网及官方账号
- 测试类型：限号计费删档测试
- 测试平台：PC、安卓、iOS

## 测试机型配置
测试版本，不代表最终配置标准

### PC端
- 推荐CPU：Intel Core i5-6500、AMD Ryzen 5 1500X及以上性能CPU
- 推荐显卡（5G显存）：英伟达GTX1060 5G、AMD RX-5500XT、Intel Arc A580及以上性能显卡
- 最低CPU：Intel Core i3-4150或AMD fx-6300
- 最低显卡（2G显存）：英伟达GTX960、AMD R9 380、Intel Arc A380或同等性能显卡
- 内存：推荐16GB及以上，最低12GB
- 存储要求：50GB以上可用空间

### 安卓端
- 推荐配置：高通骁龙865、天玑8000、麒麟9000E及以上性能CPU
- 最低配置：高通骁龙845、天玑1000、麒麟985或同等性能CPU
- 内存：推荐8GB及以上，最低4GB
- 存储要求：15GB以上可用空间

### iOS端
- 推荐配置：iPhone11及以上型号
- 最低配置：iPhone X

iPad适配进行中，本次测试暂不支持

## 报名及测试信息FAQ
### 关于招募
1.  **怎么获得双端测试资格？**

    干员们可以：
    - 前往《三角洲行动》官方网站或各平台测试招募页面，点击首页“报名测试”>>>完整真实填写并提交【代号：双子测试招募】问卷>>>提交报名信息后，即为报名成功，有机会获得测试资格；
    - 参与《三角洲行动》官方账号、社区及直播间活动，有机会获得掉落的测试资格；
    - 参与《三角洲行动》合作主播直播间，关注直播活动，有机会获得掉落的测试资格。

2.  **如何确认我是否报名成功呢？**

    完成招募问卷填写后，显示“问卷到此结束，《三角洲行动》已收到您的资格申请”的结束页提醒，以证明测试报名成功。

3.  **提交招募问卷后，我可以修改问卷信息吗？**

    提交招募问卷后，干员们无法修改问卷内已填写信息；
    如需更改个人信息，可重新填写招募问卷（多次填写不会提高入选概率，请干员们认真填写）。

4.  **我已经填写过之前的测试招募问卷，是否需要填写本次测试招募问卷？**

    未参与过代号Zero、代号C测试的干员，均需填写本轮测试招募问卷。
    如您此前已填写过其他招募问卷，可快速登记信息、或刷新近期游戏经验，均可获得额外入选BUFF。

5.  **如何确定我是否获得测试资格？**

    预计6月10日，将通过报名手机号短信、平台站内信等方式通知入选干员，也可以于资格开通后通过游戏官网查询工具自查。
    请注意，测试招募结果通知将发送至问卷所填写的手机号码，账号下载与登录权限将激活至问卷所填写的账号中。请务必确认正确填写手机号、游戏账号。

6.  **我在三角洲行动过往测试中获得了资格继承，请问是否要填写测试招募问卷？**

    参与24年3月【代号：Zero测试】与23年4月【代号：C保密测试】的玩家将自动继承测试资格。
    注：因iOS测试TestFlight有人数上限，故自动继承资格为安卓+PC资格，iOS资格申请请填写招募问卷。

### 关于测试
1.  **本次测试开始时间和结束时间是什么时候？**

    本轮测试预计6月中旬开启，具体开启及结束时间请关注后续官方社区消息。

2.  **我可以用什么账号参加测试？**

    本次测试可通过QQ或微信登录游戏，玩家可在问卷中自选希望登录的账号系统。同时会通过手机短信进行资格及活动奖励发放提醒。请各位干员正确填写QQ、微信与手机号。

3.  **QQ与微信账号互通吗？**

    QQ与微信匹配互通。本次测试每位入选干员仅开通单平台资格，请在报名问卷中准确填写平台和账号，以免资格开通失败。

4.  **如何确认我的设备是否支持本次测试？**

    请查看上文【测试机型配置】中的推荐配置与最低配置要求。

5.  **本次测试会删档吗？**

    本次双端测试为删档测试，测试结束后服务器将关停，并清除所有账号信息，请干员们注意。

6.  **本次测试支持iOS平台吗？**

    本轮测试支持iOS平台。但受限于TestFlight平台限制，iOS资格相对较少，敬请谅解。

7.  **本次测试在PC、安卓和iOS上数据互通吗？**

    互通。如干员在PC上体验后，同一个账号可以在安卓或iOS（如有iOS资格）设备上登录，可在先前的进度基础上继续体验游戏。

8.  **本次测试开放付费吗？**

    本次测试开放付费功能。iOS端因TestFlight限制，无法进行充值，干员可于PC端/安卓端进行付费充值，付费内容全端互通。
    测试期间充值返还的具体规则将另行说明，请干员们持续关注官方消息。

9.  **我是否可以将测试内容以直播、录屏、截图等信息发布到社媒平台？是否可以做直播/视频等内容？**

    在遵守法律法规及平台规则等要求的前提下，本次双端测试将不会对玩家合理的游戏内容分享、讨论及传播行为做阉割限制。但是，若玩家进行拆包、盗用、刻意抹黑等一系列侵权行为，三角洲行动将保留采取诉讼等方式追究法律责任的权利。

以上为《三角洲行动》双端测试的主要信息及常见问题解答
欢迎干员们关注官方账号查看更多资讯。
