# “DMA”外挂及“雷达”外挂打击声明

> 官方公告 | 分类：公告 | 发布时间：2025-05-27 18:00:00 | 文档ID：13238859960003493414
> 来源：https://df.qq.com/cp/a20240906main/newsdetail.html?id=13238859960003493414

干员朋友们好：
近期，我们发现网络上出现“对局雷达”等功能的违规内容，且部分外挂网页冒充伪造成官方站点恶意传播分享，严重破坏游戏环境、影响了对局公平性。

对此我们高度重视，在第一时间进行了核查及处理，现同步各位干员“雷达”外挂的实现原理及打击进展。

## 什么是“雷达”外挂
“雷达”属于外挂功能的一种，较常出现在“内核”、“DMA”等外挂样本中，其中“DMA”技术实现通过借助在副机作弊，将所获取的玩家位置、物资分布、生命值等信息呈现在游戏地图上，形成雷达地图效果。《三角洲行动》安全团队一直在对此类外挂进行打击和处罚。

近期出现的 “U*”、“E*I”、“G*K”等新型“DMA”外挂程序，更是以网页形式共享雷达地图，使其队友也能获得透视信息，严重破坏了公平性。

## 对“雷达”外挂、制售传播外挂的打击进展
《三角洲行动》安全团队一直在对 “DMA” 外挂以及“雷达”外挂进行打击。

上周内（5月19~25日）安全团队共封禁了116,813个双端作弊账号，其中45,584个为PC电脑端作弊账号，14,499个为DMA作弊账号，以上违规账号均已处以十年封禁、禁止并清除排行榜等处罚，并对相应的挂车行为进了追缴处罚。

针对制作、销售、推广外挂的网站、网页，以及传播、宣传外挂或借此获取流量的视频内容，我们已采取包括民事诉讼、行政报案、申诉举报等手段依法维权。

## 感谢热心玩家线索、感谢正义玩家朋友们！
游戏外挂属于网络黑灰产业链，购买和使用不仅违反游戏规则，将导致游戏账号被封停，还可能被不法分子利用，成为诈骗分目标造成财产损失。此外，制作和销售游戏外挂等行为均涉嫌违法，将面临法律的严厉制裁！

《三角洲行动》安全团队始终秉持"零容忍"原则捍卫游戏公平，我们将继续打击任何破坏游戏平衡、影响玩家体验的作弊行为，并将持续配合警方打击涉及游戏外挂的违法犯罪产业链！

在此，也呼吁广大干员：公平竞技的游戏环境需要你我共同守护，请各位干员健康绿色游戏，感谢大家的支持！
