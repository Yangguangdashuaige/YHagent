# 8月28日更新公告丨干员平衡性调整&航天基地、零号大坝问题修复

干员朋友们好：

我们计划于**8月28日进行不停机更新**，更新期间不会影响正常游玩与匹配；
如您在更新后遇到异常问题，可尝试重启游戏完成更新解决。
本次更新主要内容如下：

## 异常问题修复
修复了航天基地部分墙面及掩体可进入的问题；
修复了零号大坝行政楼区域陷入地下的问题。
很抱歉，由于此类问题修复更新逻辑相对复杂导致修复较慢，并持续给大家带来负面游戏体验。在此向大家诚挚道歉。
后续版本中也将加入限制区域倒计时、或终止移除进入限制区域账号的方式，来避免此类问题。
再次向大家致歉，感谢大家的谅解与包容。

## 平衡性调整
**特战干员红狼**
1、全模式
战术型烟雾弹-持续时间：7→9
2、烽火地带
三联装手炮：小幅提升对5、6级头盔和护甲的穿透伤害倍率

**特战干员威龙**
1、全模式
动力推进：将后摇允许开镜时间点提前到和允许开火一致
动力推进：落地后可以直接衔接奔跑了
磁吸炸弹：小幅减少重力倍率，调整后拥有更远的极限投掷距离
磁吸炸弹：小幅抬高出手角度，调整后拥有更远的极限投掷距离

**特战干员露娜**
1、全模式
侦察箭矢-敌方被首次暴露的时间：2.5s → 1s
侦察箭矢-降低反弹后的速度衰减幅度，增加反弹后的飞行距离
电击箭矢-加快首次伤害延迟时间 ：1 -> 0.5
电击箭矢-缩短伤害间隔：1→0.5
强化型破片手雷-中心区域满伤：120→100
强化型破片手雷-满伤半径：1m→2m
2、烽火地带
电击箭矢-电击伤害：19→5，对阿萨拉和哈夫克单位的伤害保持不变
电击箭矢-降低造成部位损伤的效率
3、全面战场
电击箭矢-电击伤害：19→13

**特战干员骇爪**
1、全模式
闪光巡飞器-从预警到爆闪的等待时间：0.9s→0.7s
闪光巡飞器-闪光时间：小幅上调PC端正面闪光的视野遮挡时间
数据飞刀-EMP效果的持续时间：5s→10s
2、烽火地带
信号破译器-扫描间隔：3→6
信号破译器-扫描波次：4→2

**特战干员牧羊人**

声波震慑-被无人机声波命中时，降低其他所有声音
声波震慑-增大无人机的受击体积
声波陷阱-被陷阱声波命中时，降低其他所有声音
声波陷阱-触发后造成效果的延迟时间：1.1s→0.7s
声波陷阱-增大陷阱的受击体积
强化型破片手雷-中心区域满伤：120→100
强化型破片手雷-满伤半径：1m→2m
2、烽火地带
声波陷阱-伤害：30→40
声波陷阱-冷却时间：30s→20s
3、全面战场
声波陷阱-伤害：60→40

**特战干员乌鲁鲁**
1、全模式
巡飞弹-子弹爆炸延迟：4.5s→3.5s
