## 后续展望

### 加强检测能力
针对透视自瞄类外挂，加强检测能力，提高实时检测及处罚的效率，从而达到在对局中实时封禁的目的，保护每一场对局的环境安全。

### 加密方案升级
游戏加密能力升级，针对多机融合、硬件外挂等外置设备的检测能力全面提升，针对"DMA"外挂设备采取更快速、更精确地检测。

### 对局回溯功能
G.T.I.Security团队将持续完善对局回溯能力，结合举报大幅提升取证效率及作弊检测能力，同时可回溯角色全部对局的全部流程与状态，确保可对历史违规行为进行复核检测，确认后追封。

G.T.I. Security 秉持“公平绿色”的原则，对《三角洲行动》的游戏环境将长期保持高度重视，任何污染游戏环境的行为我们绝不姑息，任何破坏游戏环境的行为一经发现将严肃处理并定期公示，竭尽所能保证每一位玩家的游戏体验。
