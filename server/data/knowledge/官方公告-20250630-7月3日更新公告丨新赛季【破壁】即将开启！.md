干员朋友们好：
我们计划于7月3日不停机更新游戏版本，开启全新赛季【破壁】！
预计更新节奏如下：
1. 7月3日凌晨0:30~2:00，双模式排位赛休赛暂时关闭。
2. 7月3日2:00，烽火地带模式匹配及交易功能暂时关闭。
3. 7月3日2:00，开放iOS端更新（以App Store上架新版本时间为准）。
4. 7月3日3:00，开放PC端、安卓端版本更新。
5. 7月3日9:00开放安卓渠道商店更新（以渠道商店上架新安装包时间为准）。

如您在更新期间遇到异常问题或错误提示，请在以上时间更新完成后重启游戏并更新至最新客户端版本。

更新完成后，将开启全新赛季【破壁】！

新赛季将加入：新地图潮汐监狱（烽火地带）、风暴眼（全面战场）；新突击干员克莱尔（代号疾风）；新首领渡鸦（潮汐监狱）；新武器KC-17突击步枪、复合弓；新系统特勤处收藏室、新载具、新配件与兵种道具，以及活动玩法、大量玩法优化和缺陷问题修复。

赛季更新详细内容如下，欢迎干员们查看！

## 玩法更新
### 新突击干员：克莱尔.安.拜尔斯，代号疾风
- 干员特长-爆发型辅助脊椎：附近有子弹或爆炸威胁时，疾风背部的辅助脊椎会释放电流而爆发性地增强核心肌群，提升疾跑速度。常态下可加快游泳速度。
- 战术装备-钻墙电刺：向前投掷出电刺，电刺将用钻头破开硬表面，并释放导电粉末和能击穿掩体的电流，击飞敌人手中的武器并使人短暂麻痹。
- 战术道具-战术翻滚：疾风激活背部辅助脊椎增强核心力量，向多方向快速翻滚。击倒敌人时可减少冷却时间。
- 战术道具-紧急回避装置：安装气罐后装置发射安全绳的锚点。疾风再次激活装置或受到致命伤害时，会被拉回到锚点位置。
- 在烽火地带模式中，期间倒地时可激活辅助脊椎放电除颤，进行1次倒地自救。
- 在全面战场模式中，拉回期间疾风将能够短暂承受超出生命值上限的伤害。
- 安全绳在疾风坠落一定距离时会进入悬挂状态。

## 新动作——游泳
- 当潜入水中时，将会消耗氧气；当浮出水面，氧气将开始恢复。氧气耗尽将会持续扣除生命值。
- 可选择慢速游泳或冲刺游泳；冲刺游泳会消耗体力并加速氧气消耗。
- 当角色在水面时，可使用武器开火、可使用所有道具；角色在水下时，不可使用武器开火，仅可使用部分道具；当角色由水下浮至水面时，有短暂的开火延迟。
- 武器可以从水上射入水下，但进入水下后存在非常快速的伤害衰减。
- 烽火地带中被击倒可以在水中缓慢自由移动；全面战场中被击倒会自动上浮至水面，但无法自由移动。
- 烽火地带中可前往特勤处-潜水中心处提升等级，强化角色相关能力。

威龙因为其高灵活度，高上限的能力组合，在烽火地带的各地图中拥有远超其它干员的数据表现。在经过两个赛季的观察后，我们决定在不影响其核心玩法循环的前提下，先对其进行小幅度的数值平衡，并持续关注其平衡性表现。
