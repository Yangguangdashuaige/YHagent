# 《赛季任务短周期补偿公告》

> 官方公告 | 分类：公告 | 发布时间：2025-09-25 17:42:17 | 文档ID：4378738409412303416
> 来源：https://df.qq.com/cp/a20240906main/newsdetail.html?id=4378738409412303416

**干员朋友们好：**
**由于本赛季为短周期赛季，时长少于常规赛季，我们看到了大家对于赛季顶级安全箱可用时间的反馈和建议。**
**对此我们将通过以下方式进行补偿：**
**1、完成当前赛季任务，并拿到“3×3安全箱”的干员，在下赛季初补发20天“3×3安全箱体验卡”，补齐赛季时间差量。**
**2、未完成当前赛季任务，但完成了一定阶段行动计划的干员，也将根据赛季结束时完成的1-3个任务阶段，给予5/10/15天的体验卡补偿。**
**3、此外，根据干员们在本赛季的任务【阶段】进度，我们还将发放对应数量的“赛季任务特种装备券”，作为下个赛季的启动物资，助力大家游玩并更快参与后续挑战。**
**以上补偿内容（包括“3x3顶级安全箱体验卡”和“赛季任务特种装备券”）均将于下赛季开启后，通过游戏内邮件统一发放，数据统计预计需要一些时间，届时请大家稍事等待，及时查收。补偿中的3x3顶级安全箱体验卡仅下赛季内有效。**
**感谢各位干员对《三角洲行动》与赛季任务的理解与支持！**

**祝大家游戏愉快！**

**《三角洲行动》项目组**
**2025年9月25日**
