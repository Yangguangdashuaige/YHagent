# 11月13日更新公告丨新赛季【阿萨拉】即将开启！

> 官方公告 | 分类：公告 | 发布时间：2025-11-10 17:59:18 | 文档ID：9257832193577242942
> 来源：https://df.qq.com/cp/a20240906main/newsdetail.html?id=9257832193577242942

干员朋友们好：
我们计划于11月13日不停机更新游戏版本，开启全新赛季【阿萨拉】！
预计更新节奏如下：
1. 11月13日凌晨0:30~2:00，双模式排位赛休赛暂时关闭。
2. 11月13日2:00，烽火地带模式匹配及交易功能暂时关闭。
3. 11月13日2:00，开放iOS/鸿蒙端更新（以应用商店上架新版本时间为准）。
4. 11月13日3:00，开放PC端、安卓端版本更新。
5. 11月13日9:00开放安卓渠道商店更新（以渠道商店上架新安装包时间为准）。

如您在更新期间遇到异常问题或错误提示，请在以上时间更新完成后重启游戏并更新至最新客户端版本。

更新完成后，将开启全新赛季【阿萨拉】
新赛季将加入：新地图金字塔（全面战场）；新工程干员；烽火地带新事件；红鼠窝竞技场新地图；新武器MK4冲锋枪；新弹药，新消耗品，新针剂以及赛季任务系统优化、大量玩法优化和缺陷问题修复。

赛季更新详细内容如下，欢迎干员们查看！

## 玩法更新
### 新工程干员：拉希德.拉哈尔，代号比特
- 干员特长-防守尖兵：在自身的部署物附近时获得提高武器操控速度的增益效果；
- 战术装备-哨兵母巢：部署一个包含三只哨兵蜘蛛的机械母巢，哨兵蜘蛛会接近追踪敌人并爆炸，对敌人造成伤害并附着腐蚀效果，增加敌人受到的子弹伤害，被腐蚀的敌人进入智能烟雾中会被标记；

## 局内战斗&关卡优化
### 全模式
- 现在支持在高速移动平台上进行翻越与移动；
- 干员手势现在可被各类操作中断；
- 调整了头部受击时角色的动作幅度，避免角色受击时身体移动幅度过大导致的不平衡问题；
- 优化了快速游泳时切换、收起武器的表现；

### 烽火地带
- 调整了救援与使用药品在不同楼层的声音效果，以使其能够更加清晰得被辨别；
- 踹门音效传播距离增大至50米，且声量衰减更缓慢；
- 爬梯音效现在将受到拾音范围效果影响；
- 略微增加了反复切换疾跑状态的体力消耗；
- 高价值物品检视：军用无人机，呼吸机，纵横新增检视动作。
- 长弓溪谷：长弓溪谷现在不再会燃起山火。

### 全面战场
- 全面战场载具平衡性调整：
  - LAV-G1步战车：尾翼稳定穿甲弹：200米内对四肢伤害：94 → 100，200米外对四肢伤害：85 → 90；高爆弹：75米内命对四肢伤害：95 → 100，75米至125米对四肢伤害：72.5 → 75，125米外对四肢伤害：59 → 60；
  - F-45A战斗机：降低了悬浮模式偏航与俯仰机动性；移动端第三人称增加速度和高度信息显示；
- 断轨：
  - 调整了掩体位置，优化了载具的通过性；
  - 对部分区域进行小幅场景调整，使对局体验更加平衡；将部分静态掩体替换成了可破损掩体。
  - 攻防模式下调整了据点A的固定机枪位置；
  - 占领模式下新增F-45A战斗机，攻守双方各增加一辆LAV-AA防空车，将全阵营可部署的全地形车调整为仅己方小队可部署；
  - 占领模式下删除了部分滑索。
- 断层：
  - 据点A1，A2合并为据点A；
  - 调整了据点A的重新部署点的位置；
  - 调整了据点A的交战区域边界；
  - 优化了彩蛋触发的点位，修复了其在移动端浮空的问题。
- 攀升-攻防：
  - 调整了据点D的进攻方交战区域；
- 攻防模式阵地支援-空投载具消耗分数调整：
  - LAV-AA防空车：分数消耗调整为6500分；
  - LAV-G1步战车：分数消耗调整为10000分；
  - FSV轮式突击炮：分数消耗调整为8000分；
  - GTQ-35轻型坦克：分数消耗调整为9500分。
- 线控导弹：优化移动端线控导弹一键开火逻辑，开镜后松开射击键才会发射导弹，并可通过准心持续引导；

### 胜者为王
- 战前部署阶段新增【指挥官分队】功能：战前部署阶段中，指挥官可选择两种小队分配模式：
  - 选择【王牌小队】会优先将所有职责能力达到黄金等级的玩家集中分配到同一小队；其他玩家按照职责配比自动分配；
  - 选择【全面进攻】会优先将所有职责能力达到黄金等级的玩家平均分配到各个小队；其他玩家按照职责配比自动分配；
  - 选择分配模式后，指挥官可变更非组队玩家的所属小队；组队进入对局的小队不会被分配功能拆分；
  - 指挥官可在分队阶段指派小队长。
- 阵地支援-空投载具消耗分数调整：
  - LAV-AA防空车：分数消耗调整为7500分；
  - LAV-G1步战车：分数消耗调整为10000分；
  - FSV轮式突击炮：分数消耗调整为9000分；
  - GTQ-35轻型坦克：分数消耗调整为9500分。
- 攀升-胜者为王：
  - 调整了据点D的进攻方交战区域；

## 系统优化
### 全模式
- 新增手柄功能：
  - 新增左摇杆线性移动支持，根据摇杆推动幅度决定人物移动速度；
  - 新增右摇杆输入平滑支持，右摇杆操作将更加顺滑；
  - 新增多种换弹/交互方式：优先换弹/优先互动/点按换弹长按交互/长按换弹点按交互；
  - 优化了灵敏度预设，从低中高预设变为1-8不同分级的灵敏度预设，给玩家更多选择，更容易找到适合的灵敏度；
  - 优化了组合键输入的表现，减少卡键和组合键触发困难的问题；
  - 新增了UI尺寸设置，在“设置-界面”下选择（目前仅支持部分UI，持续优化中）；
