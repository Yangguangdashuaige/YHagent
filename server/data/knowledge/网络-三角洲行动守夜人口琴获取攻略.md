# 三角洲行动守夜人口琴获取攻略
### 道具说明
守夜人口琴是二周年（S11）限定红色藏品（估值288888哈夫币），可放入工具包带入对局吹奏，也是解锁火箭大红“阿萨拉一号”的前置道具。
### 前置条件
需在普通模式长弓溪谷完成NPC佐拉的6阶段任务线；每天最多做2个任务，现实时间凌晨0点刷新，最快3天完成。
### 任务接取点位
储藏站下方山洞（原“黄金鸟窝”彩蛋点位）——跳上箱子爬进洞口，分叉路往左走至入水口，游泳进洞找到佐拉，等她坐下后反复对话接取任务。
### 六阶段任务流程
1. **英雄头盔**：击败钻石皇后酒店/雷达站BOSS雷斯，拾取其盒子旁边地上的头盔（不用自己击杀，别人打死也会刷新；注意捡地上的而非盒内的），带回交佐拉，随后重开新局。
2. **英雄护甲**：游到山洞最深处鳄鱼池，击杀全部尼罗鳄（约7只），拾取盒子旁刷新的护甲交回，之后需等次日0点刷新。
3. **特殊枪械配件（共7个，占10格）**：四个点位：
   - 加尔比旧址左上角小屋棺材内：3个
   - 皇后酒店外侧、通往交易桥马路上的坦克上：1个
   - 阿米娅小镇狙击塔最高处白色空调外机旁：1个
   - 储藏站下方铁穹瀑布雷区中心：2个
   集齐交佐拉组装成枪，重开新局。
4. **送物资换弹挂**：提前在交易行买好低级燃料、军用罐头、医用酒精、纯净水，到阿米娅小镇两栋红房子，从房门铁栅栏缝隙提交——上面的房子交燃料+罐头，下方长条形房子交酒精+纯净水；撤离重开一局后，在小镇高塔下方拾取居民放的英雄弹挂交佐拉。
5. **英雄背包**：潜入皇后酒店下方水域最深处的水下洞穴拾取。洞内昏暗，建议手枪装枪灯、升满氧气/游泳体力，推荐组队（张姐有游泳移速加成、蝶负责接应救人，或用干员“疾风”防溺水）。
6. **最终决战**：穿上山洞衣架上的全套阿萨拉任务装备，前往超星车站、雷达站清剿全部哈夫克人机；清完后雷达站会刷新蓝鹰直升机，将其击毁，回山洞与佐拉对话并撤离。
### 奖励领取方式
6阶段全部完成后退出对局，奖励通过游戏邮件发放，装备后在对局内按对应按键即可吹奏。
### 注意事项
- 该任务为周年限定内容，建议尽早完成；
- 各环节之间通常需重开新对局或等待0点刷新才能接取下一步。
