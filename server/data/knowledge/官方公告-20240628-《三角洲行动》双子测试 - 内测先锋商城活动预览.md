# 《三角洲行动》双子测试 - 内测先锋商城活动预览

> 官方公告 | 分类：公告 | 发布时间：2024-06-28 11:35:08 | 文档ID：16476818037791327259
> 来源：https://df.qq.com/cp/a20240906main/newsdetail.html?id=16476818037791327259

干员朋友们好：

为答谢干员们积极参与双子测试，本次测试将开放内测先锋商城活动。

在该活动中各位干员可以使用内测先锋币兑换限定外观奖励，奖励将分阶段解锁，所有在该活动中获得的外观奖励均可保留至游戏正式上线，欢迎在游戏内查看参与互动。

参与方式：游戏内活动页面 - 普通活动 - 内测先锋商城

奖励内容：枪械外观、载具外观、军牌/喷漆/头像等

活动规则：双子测试期间，参与指定活动，完成任务获得内测先锋币，前往内测先锋商城兑换外观奖励。

在内测先锋商城活动页面左侧可查看到当前可获取内测先锋币的活动，请各位干员在完成任务后及时领取奖励。

《三角洲行动》项目组
