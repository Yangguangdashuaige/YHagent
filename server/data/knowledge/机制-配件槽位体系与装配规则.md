# 机制详解：配件槽位体系与装配规则（枪口随枪管、护木套件、出厂固定件）

本文解答：一把枪有哪些配件槽、为什么有些枪"没有枪口位"、护木套件为什么能解锁枪托、哪些配件不能拆。适用于烽火地带（烽火）改枪。

## 常见槽位一览

| 槽位 | 说明 | 典型配件 |
|---|---|---|
| 枪管（barrel） | 每把枪有若干根可选枪管 | 短管/标准管/超长管 |
| 枪口（muzzle） | 消音器、消焰器、补偿器 | 并非所有枪都有独立枪口位 |
| 护木（foregrip/handguard） | 前握把、护木本体 | 垂直握把、斜握把 |
| 枪托（stock） | 影响据枪与操控 | 固定托/无托转换 |
| 弹匣（magazine） | 容量与操控的取舍 | 大弹匣/快拔弹匣 |
| 瞄准镜（optic） | 主瞄具 | 红点/全息/倍率镜 |
| 侧瞄具/导轨件 | 辅助瞄具、激光 | 侧导轨红点 |

## 枪口位是"随枪管走"的条件槽

关键机制：**枪口槽不是每把枪固定拥有的槽**，它由当前安装的枪管决定——每根枪管自带它支持的枪口件清单。例如 M14 的 5 根可选枪管，每根各解锁 3 个枪口件（轻语战术消音器、死寂消音器、先进多口径消音器等）。

因此"换枪管后枪口件能不能留"要看新旧枪管是否支持同一枪口件；换短管经常意味着枪口件也得换。部分武器天生无枪口位：霰弹枪、复合弓，以及 AS-Val/VSS 这类**一体消音**枪械（消音器焊死在枪管上，不可拆卸）。

## 护木套件与耦合规则（coupling）

有些配件会**联动解锁**其他槽位：最典型的是"护木套件"——装上后解锁原本不存在的枪托槽。这类装配规则叫耦合（coupling）：

- 装配件 A → 解锁槽位 B（装了护木套件才能装枪托）
- 极少数配件会**封锁**某槽位（占用导轨空间），表现为该槽位变灰不可选

判断顺序：先选大件（枪管、护木套件），看解锁/封锁了什么，再选小件。

## 出厂固定件：不能拆的配件

部分枪械出厂自带不可拆卸的配件（playerSelectable=false，即"固定件"）：例如 M14 的默认枪管就是出厂固定件——你能选的是"换哪根枪管"，而不能"不装枪管"。固定件在改枪界面通常显示为默认选中且无法取消。

## "未安装"也是合法选择

除固定件外，大多数槽位允许**空着不装**（如不安侧瞄具、不安前握把）。空装方案在数值上= 该槽位修正为 0。搜索"所有满足据枪+8 的改法"时，漏装某些槽位的方案同样是合法解。
