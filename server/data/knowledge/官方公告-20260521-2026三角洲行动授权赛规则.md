# 2026三角洲行动授权赛规则

> 官方公告 | 分类：公告 | 发布时间：2026-05-21 18:02:50 | 文档ID：8724920629688715740
> 来源：https://df.qq.com/cp/a20240906main/newsdetail.html?id=8724920629688715740

## **一、 ** **简介**

1. 授权赛事定义：由三角洲行动赛事组委会外第三方，在获得三角洲行动赛事组委会官方授权后主办的三角洲行动赛事，被定位为三角洲行动授权赛事，包含各不同类型、规模、报名范围的赛事。
2. 在办赛方遵守本规则约定，并按要求进行备案、获取授权的前提下，我们授予办赛方一项可撤销、不可转让及非排他性的许可，包括：

- 三角洲行动办赛权（烽火地带和全面战场需要独立申请）
- 三角洲行动游戏画面使用权（仅限赛事内容）
- “三角洲行动”赛事名称使用权（不可与商业客户权益同框）
- 赛事素材使用：详情见IP素材列表（限赛事宣发使用，不可与商业客户权益同框）

3. 所有赛事内容及主办方赛事宣传内容，均需要标注“本赛事为授权型赛事，由xxx主办”，字号不得小于其他内容。

## **二、 ** **赛事授权流程**

1. 前往赛事授权平台游戏人生赛事合作平台，完成资质认证后发起办赛申请，并附完整赛事方案进行审核（包括但不限于：赛事名称、赛事规模、比赛模式、主办方信息、比赛时间、赛程计划、报名方式、招商计划、宣发计划、奖项明细）。
2. 大型授权赛（奖金≥50万）赛事时间不得与三角洲官方赛事时间冲突。
3. 办赛方至少需要在赛事启宣前3个月，向三角洲行动赛事组委会提出授权赛申请。
4. 赛事内容、商业权益、物料需符合官方规定，并在开赛前5日提交并完成审核。

## **三、 ** **官方办赛工具**

1. 为了提高赛事主办方的办赛便捷性，全部烽火行动模式授权赛均需要使用官方提供的办赛工具，该工具支持赛事报名、赛程管理、账号初始化、道具下发等功能。
2. 全面战场模式暂不提供办赛工具，提交账号开通自建房权限。

## **四、 ** **招商及权益规范**

1. 允许赛事招商，招商权益仅限于赛事本身内容，不能使用三角洲行动相关IP权限进行商业化，包括但不限于三角洲行动游戏名、三角洲行动游戏LOGO、游戏形象、游戏素材、三角洲行动赛事口径等（例如：三角洲行动赛事合作伙伴）。
2. 客户准入：招商权益细则及客户名单，需要在承诺客户前，先提交至三角洲行动赛事组委会审核确认；官方有权对招商方案进行指导建议和修改，对资源位有修改权，对报价有指导建议权，且对招商方案保有单方一票否决权。
3. 素材使用：赛事相关物料（包含线上、线下全部物料），三角洲行动相关IP素材不得与任何主办方、主办方客户、主办方合作单位或无关第三方的品牌、产品、名称及相关元素、权益等进行同框使用(含宣传物料同框、线下区域摆放同框、线下墙体摆放同框、拍照同框及任何同框场景)。
4. 招商合作品牌在同行业类别中需属于前列或主流，品牌属性健康，禁止与以下类型客户进行任何形式直接或间接合作

## **五、 ** **赛事名称规范**

1. 避免和三角洲行动官方赛事重名，禁止出现含包括但不限于烽火杯、烽火世界杯、全面战场国际邀请赛、职业（联赛）、全国大赛、高校赛、全面打洲杯，主播巅峰赛（以官方实际发布赛事名称为准）即可以代表三角洲官方赛事的词汇，包括全称和简写。
2. 避免办赛方为了制造话题和噱头，不切实际地放大赛事规模，如：全国、全省、全市等区域性名称。若办赛方在赛事命名中体现市及市以上的区域范围限定词汇，需要满足相应的赛事规模和报名范围，不得标榜省、市级代表队等官方称谓。
3. 三角洲行动授权赛均为免费的，非独家的，应避免办赛方夸大宣传，不能在赛事宣传中使用如下词汇：唯一、指定、特许、独家等，但赛事宣传中可以使用“官方授权”描述。
4. 赛事名称及简称，在赛事启宣前，先提交至三角洲行动赛事组委会审核确认；官方有权对赛事名称进行指导建议和修改，且对赛事名称保有否决权。

## **六、 ** **素材使用规范**

1. 三角洲行动“授权素材包内容”仅限赛事本身使用，包含赛事内容及主办方赛事宣传内容。
2. 三角洲行动“授权素材包内容”仅限于赛事本身使用，不得和主办方产品、主办方客户、主办方合作单位或无关第三方的品牌、产品、名称及相关元素、权益等进行同框使用，严禁用于任何形式的商业用途。
3. 所有授权赛使用的对外传播素材（包括但不限于：赛事KV、宣传图、稿件、H5、赛事官网）需经《三角洲行动》官方监修通过后方可对外发布使用，且素材造成的一切影响，均由被授权方独自承担。
4. 三角洲“授权素材包内容”包含：



| IP素材内容 |
| --- |

| 模式名称《烽火地带》 |

| 游戏画面 |
| 游戏LOGO和游戏ICON |
| 三角洲品牌KV |
| 部分干员形象 |
| 游戏字体 |

## **七、 ** **赛事条款规范**

1. 综合型赛事中，如包含同类型游戏赛事，包括但不限于第一人称射击游戏、第三人称射击游戏、搜打撤类游戏，为保证用户体验，需要在申请时写明。
2. 禁止向参赛玩家收取任何形式的费用（包括但不限于：收取报名费、押金、抵扣税金、入场费、保证金）。
3. 办赛方需要统计赛事相关数据（包含但不限于：报名人数、参赛人数、现场观赛人数、线上播出数据），并在赛事结束后输出赛事总结。
4. 授权赛赛制可以自行制定，但需保证赛制公平，且三角洲行动赛事组委会有一票否决权，未经批准的赛制不允许使用。
5. 禁止18岁以下未成年用户参赛。
6. 不得在任何状况下，以口述、文字或其他方式，宣传、讨论、提及违规或灰色业务，禁用的关键词包括但不限于：防沉迷、未成年、外挂、代练、道具售卖、护航、陪玩、账号租借、账号交易等名词）。
7. 仅三角洲行动赛事组委会有权授权举办三角洲行动赛事，任何组织、机构、APP、网站等不可宣称授权三角洲行动赛事或提供申请办赛平台。
8. 已获得的三角洲行动赛事授权仅限该授权赛本身，不可转授第三方，授权使用的《三角洲行动》IP 形象、办赛权益、办赛工具等内容，仅能在合作范围与时间内使用，不允许超出合作范围与时间使用，不允许转授权、分许可。
9. 在赛事方案、参赛须知、选手手册里必须体现，并征得所有参赛选手同意（书面或选手群内文字回复同意）：报名参加本赛事即同意：为保证比赛公平性与比赛的正常进行，在需要进行账号安全检测的情况下，赛事主办方可以收集选手的参赛过程中（以参赛账号登录为准）所使用的设备信息（设备型号、是否越狱或root等）、参赛账号信息（区服、UID、角色名等）等必要的用于账号安全检测的信息，并可以向深圳市腾讯计算机系统有限公司提供上述信息以用于账号安全检测。

## **八、 ** **直播行为规范**

1. 赛事内容需符合国家政府对于直播/录播的相关政策和法规监管要求，并自行完成备案审核。
2. 内容包装和格式，请提前给予赛事组委会确认，如直播中穿插合作方信息或赞助信息，也需同步说明并参照内容及素材展示规范，组委会拥有修改及否决权利。

## **九、 ** **奖励和荣誉**

1. 合作方全权负责授权赛奖励物品的获取、发放以及相关信息统计工作，如因自有奖励产生的用户纷争，需及时妥善处理。
2. 赛事奖励及荣誉的设置需符合三角洲行动的品牌形象和市场定位，不得包含违法违规、低俗或损害游戏或腾讯公司声誉的内容。所有奖励及荣誉的执行方案须在赛事启动前报三角洲行动赛事组委会审批，经审核通过后方可执行。

## **十、 ** **法律规则**

1. 管辖与法律适用
- 授权协议签订单位为 腾讯科技（深圳）有限公司。签订地为深圳市南山区。
- 授权协议的成立、生效、履行、解释及纠纷解决，适用中华人民共和国大陆地区法律（不包括冲突法）。
- 若被授权方和《三角洲行动》赛事授权方之间因本协议发生任何纠纷或争议，首先应友好协商解决；对于无法通过协商解决的，被授权方同意将纠纷或争议提交至本协议签订地有管辖权的人民法院管辖。
- 本协议所有条款的标题仅为阅读方便，本身并无实际涵义，不能作为本协议涵义解释的依据；本协议条款无论因何种原因部分无效，其余条款仍有效，对各方具有约束力。

2. 相关追责
- 若授权赛事活动发生任何违反国家法律的行为，皆与《三角洲行动》赛事授权方无关。
- 若授权赛事活动发生任何造成玩家生命为害的行为，皆与《三角洲行动》赛事授权方无关。
- 若授权赛事活动发生任何对玩家体验造成不良影响（包括但不限于：现场秩序混乱、赛事长时间中断）的行为，皆与《三角洲行动》赛事授权方无关。
- 若授权赛事活动出现任何不良办赛行为（包括但不限于：临时取消办赛、奖金拖延发放）投诉行为，皆与《三角洲行动》赛事授权方无关。
- 被授权方应自行负责活动素材的合法使用，自行承担审核义务。被授权方使用非官方提供的第三方素材（包括二创内容）所产生的一切侵权责任，均由被授权方独立承担，与《三角洲行动》赛事授权方无关。

## **十一、 ** **官方管理规范**

1. 办赛方需同意《三角洲行动》官方参与推广其赛事，并可根据办赛方比赛结果，邀请授权赛选手参加《三角洲行动》官方主播、协办、赞助的比赛。
2. 通过官方渠道授权的第三方赛事公司，同意永久并免费授予《三角洲行动》官方使用授权赛中直播内容、VOD、录像、视频、新闻、赛事素材和现场图片的权力，《三角洲行动》官方可以复制、修改、分发、公开展示或向其他渠道、平台提供此部分的内容。
3. 《三角洲行动》官方有对造成不良影响、玩家投诉、违反授权规则的授权赛有权随时撤销比赛的授权许可。
4. 授权赛需在遵守相关法律法规的前提下开展，确保所有参赛队伍、选手、观众的赛事体验。主办方需设立清晰透明的投诉举报机制和反馈收集渠道，若官方通过任何渠道收到赛事相关投诉，官方有权利随时暂停该授权赛事。
5. 若授权赛事宣传中出现了任何与《三角洲行动》价值观不符的内容，《三角洲行动》有权随时撤销比赛的授权许可。

## **十二、 ** **奖惩规范**

1. 对于以下合作行为的赛事，赛事组委会将予以积极奖励，全力支持，且合理诉求会优先给予安排
- **卓越的社会声誉与玩家口碑：**办赛方具备良好的公众形象，其运营活动获得玩家社区的积极评价。这意味着合作方不应有重大的违规记录或引发恶劣影响的投诉事件，能够为《三角洲行动》带来正面的社会影响力。
- **长期的战略合作意愿** ：办赛方展现出长期合作的诚意与规划，而非短期逐利。这体现在其积极参与合作的态度上，例如，能够及时响应官方需求，保持高效、顺畅的沟通，并在多次合作中展现出持续的配合度与投入度。
- **具备反哺生态与贡献价值的能力** ：办赛方能够为《三角洲行动》游戏及官方赛事带来实质性资源支持，例如协助扩大赛事影响力与规模，并能从市场一线提供有价值的洞察与建设性意见，共同促进赛事与游戏生态的健康发展。
- **紧密配合官方节奏与用户利益至上**：办赛方能够积极支持官方的各类运营活动与关键节点（如版本更新、重大节日活动等）。其核心行动辅助提升《三角洲行动》玩家的利益与游戏体验，并主动协助官方推广新的游戏产品、模式及玩法，实现共赢。

2. 对于违反本文档规范条款任意1条的授权合作，官方将予以警告，限期整改符合标准后再予以执行。
3. 若同时违反上述条款2条及以上，或违反任意1条2次以上的授权合作，官方将立即解除合作，由此造成的经济及其他损失由被授权方自行承担。
4. 出现违反上述条款3条及以上，且沟通态度恶劣，拒不改正的情况，官方除立即叫停赛事和相关异业合作外，还有权将该赛事、赛事执行方、异业合作方等相关单位列入黑名单，永不合作。
5. 如办赛方违规情节严重，给官方造成严重恶劣影响或引起民事、经济纠纷的情况，官方将委派法务人员依法追究办赛方的法律责任和造成的损失。
