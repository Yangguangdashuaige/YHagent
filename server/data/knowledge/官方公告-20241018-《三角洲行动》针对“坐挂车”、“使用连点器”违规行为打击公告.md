# 《三角洲行动》针对“坐挂车”、“使用连点器”违规行为打击公告

> 官方公告 | 分类：公告 | 发布时间：2024-10-18 18:28:08 | 文档ID：4402136629018862783
> 来源：https://df.qq.com/cp/a20240906main/newsdetail.html?id=4402136629018862783

干员朋友们，大家好！

《三角洲行动》安全分队G.T.I.Security致力于打造绿色健康、公平竞技的游戏环境， 我们通过游戏内7*24小时全天监测，对于任何违规行为，在经核实后将给予相关处罚。
上线以来，我们监测到有部分玩家通过“坐挂车”获取不当收益，对游戏公平环境产生破坏，也对其他玩家的游戏体验造成了严重的影响。
“坐挂车”一直是我们重点打击的违规行为，我们回溯了近期的对局组队，根据【近段时间与作弊违规账号主动组队】的对局情况，对违规账号进行了相对应的警告及处罚，上线以来，共警告52816个违规账号，处罚、追缴收益并罚款9031个违规账号。
**注：“坐挂车”处罚只针对：主动与作弊账号组成队伍，共同匹配进入对局多次的情况。随机匹配不计入“坐挂车”检测**。
