**干员朋友们好：**

**《三角洲行动》代号:Zero测试将于3月7日正式开启！**

**首批测试已于3月5日陆续发放，您可以通过以下方式确认是否获得首批测试资格。**

**资格查询方式**
**方式一：游戏官网（df.qq.com）查询**
1, 进入官网，登录报名使用的QQ账号；
2, 点击测试资格查询；

**方式二：报名预留的手机号码短信**
1, 收到《三角洲行动》测试资格短信即为开通资格；
2, 手机短信可能被系统屏蔽，也可打开短信垃圾箱/回收站查看；
3, 手机短信仅做通知，请以游戏官网最终显示结果为准；

**常见问题FAQ**

**Q1：获得资格后做什么，怎么下载？**
A：官网查询资格如显示已获得资格，请点击下载游戏，即可下载游戏启动器及客户端版本。

**Q2：没获得资格，后面还会继续开吗？**
A：首批资格3月5日发放，后续我们会视情况补录，请留意官网及官方账号消息。

**Q3：下载好了，什么时间开服？**
A：测试预计3月7日9点30分正式开服。

**Q4：我在官方社区账号、活动中获得的资格，可以预下载吗？**
A：可以，请在官网登录获得资格的QQ号，即可预下载，如遇问题请联系资格掉落平台管理员。

**Q5：我在活动/直播/线下试玩/或其他途径获得了测试资格，但没有开通成功，怎么办？**
A：请优先核对是否登录了正确的QQ账号；确认无误可先联系发放资格的平台管理员、或联系官方Q群管理员提交信息核实补录资格。
