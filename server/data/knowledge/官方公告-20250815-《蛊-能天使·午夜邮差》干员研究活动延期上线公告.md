# 《蛊-能天使·午夜邮差》干员研究活动延期上线公告

> 官方公告 | 分类：公告 | 发布时间：2025-08-15 04:11:26 | 文档ID：16992539507664683888
> 来源：https://df.qq.com/cp/a20240906main/newsdetail.html?id=16992539507664683888

干员朋友们好：
很抱歉，深夜打扰大家。
昨晚，我们发布了《蛊-能天使·午夜邮差》干员外观的相关内容后，收到了许多玩家的吐槽。对此，我们向关注本次方舟联动、以及喜爱两位联动角色的干员朋友们，表示诚挚的歉意。

很抱歉，我们决定延期上线《蛊-能天使·午夜邮差》干员研究，并将奖池中的‘能天使-勇士冲锋枪’，替换成为‘能天使-Vector冲锋枪’。
替换完成并确认上线时间后，我们将第一时间公告告知大家。

‘能天使-勇士冲锋枪’将直接作为延期上线补偿全服发放，除此之外还将发放补偿道具：精锐制式装备券*1、零号大坝藏宝图补给包*1、巴克什藏宝图补给包*1、双倍军功卡*1、军功保护卡*1、武器高级经验卡*5。

对于这一事故，我们也在内部进行了严肃复盘，在此将事件过程还原如下：
原计划在对《蛊-能天使·午夜邮差》联动活动设计时，预设的搭配武器是‘Vector冲锋枪’，所以在相关素材制作时采用了‘Vector冲锋枪’为搭配武器。
但在近期对资源进行测试和验证时，我们发现‘能天使-Vector冲锋枪’存在立绘错误和还原不严谨的问题。经评估，该武器难以在8月15日活动上线前修改完毕。为了实现先前承诺按时上线，我们做了一个非常不严谨的错误决策——替换活动搭配武器，将已经完成设计和测试验证流程的‘能天使-勇士冲锋枪’加入活动。
但此番鲁莽的替换操作也让关注本次联动、喜爱能天使的干员们感到疑惑和不满，对此，我们深刻地意识到了错误。我们将加速‘能天使-Vector冲锋枪’的调整与优化，让活动尽快上线。

再次向所有关注联动和活动的干员们致歉，感谢大家的谅解和包容。
