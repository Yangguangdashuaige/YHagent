# 《三角洲行动》双子测试结束预告

> 官方公告 | 分类：公告 | 发布时间：2024-08-27 17:08:07 | 文档ID：13866721190136758627
> 来源：https://df.qq.com/cp/a20240906main/newsdetail.html?id=13866721190136758627

各位干员朋友们，大家好！

**《三角洲行动》双子测试将于2024年9月8日24时结束。**
测试结束后将关闭双子服务器，处理并记录双子测试充值返还及内测先锋活动数据；所有账号的游戏昵称、好友关系、游戏战绩、仓库道具、哈夫币及账号等级等非继承数据将删档，不会继承至正式上线阶段。

**关于充值返还、内测先锋商城活动的规则如下，请您知悉：**

充值返还：如您在双子测试中充值三角币，将按照充值返还规则记录，游戏正式上线后您可以前往充值返还活动页面领取三角币到当前账号上。
此外，如您在双子测试中获得过典藏系列外观，可免费选择保留一款，游戏正式上线后也将直接发送到您的游戏内邮箱。

充值返还规则+典藏系列保留活动地址：《三角洲行动》充值返还活动

内测先锋商城活动：如您在双子测试“内测先锋商城”活动中获得“先锋币”，可在该活动中兑换奖励并保留，游戏正式上线后也将直接发送到您的游戏内邮箱。

内测先锋商城活动地址：游戏内大厅-活动-内测先锋商城

** 还未选择保留典藏系列外观、或兑换内测先锋币的干员请及时选择保留或兑换奖励**

其他内测活动奖励、预约奖励等内容请于游戏正式上线后查看游戏内邮箱（可能有些许延迟），或对应预约平台领取。
感谢各位关注、支持和参与《三角洲行动》双子测试的干员朋友，大家的帮助和鼓励使我们不断进步、变得更好！
我们也将在近期公布正式上线时间，9月不见不散！

**《三角洲行动》项目组**
